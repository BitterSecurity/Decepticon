# Repository contribution instructions

Before creating or updating a pull request, read [Chagelog.md](Chagelog.md) and
update the canonical [CHANGELOG.md](CHANGELOG.md) under **Unreleased** for
user-visible changes. Link the issue and pull request; identify proposed changes
as proposed until merged. Do not put unmerged changes in a released section or
bump versions as part of this bookkeeping.

This applies to documentation and maintenance PRs too. Preserve prior history;
on release, use the real version or immutable release identifier and release
date. Distinguish proposed, merged, and deployed changes without unrelated
version bumps. Link `Chagelog.md` from the PR description.
