# Engagement lifecycle moved to runtime workflows

This directory no longer exposes a SKILL.md asset. Fixed phase transitions,
initiation, reporting and emergency procedures belong to the selected WORKFLOW.md.

The four builtin workflows preserve required scope/context, objective/evidence
reconciliation, independent verification and reporting. The red-team workflow
preserves conditional access expansion, deconfliction, attributable detection
metrics and cleanup accounting. Common workflow instructions preserve abort and
resume behavior. A supplied source tree or PoC can bypass redundant discovery;
a universal recon → exploit → post-exploit sequence is intentionally not retained.

Technical causal analysis remains in kill-chain-analysis and evidence/context
interpretation remains in orchestration. The former SKILL.md is recoverable from
repository history; no workflow procedure is duplicated into a replacement skill.
