# Engagement startup moved to runtime workflows

This directory no longer exposes a SKILL.md asset. Startup and resume are business
procedures selected by a runtime workflow, not reusable technical methods.

The four `decepticon/workflows/catalog/*/WORKFLOW.md` documents retain the applicable
workspace binding, required RoE, optional planning-document handling, plan revision,
evidence prerequisites and authorized dispatch requirements. Soundwave remains the
separately selected planning adapter. Missing authorization is never repaired by an
operational specialist. See docs/design/workflow-authoring.md and
bugclaw-core-extraction.md for the ownership boundary and reviewed migration.

The former SKILL.md is available in repository history. Callers should select a
registered workflow ID rather than requesting this retired skill name.
